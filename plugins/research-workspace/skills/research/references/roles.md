# Oh My Paper-derived roles

Adapted from Oh My Paper's five-role harness; upstream attribution is in THIRD_PARTY_NOTICES.md.

| Role | Read as needed | Responsibility |
| --- | --- | --- |
| Conductor/coordinator | Project index, tasks, decisions, reviews, handoffs | Clarify scope, plan, review outputs, maintain shared accepted state. Can perform a small task itself; delegation is optional. |
| Literature Scout | Research question, source notes, rejected directions | Search and screen literature; distinguish full text from abstract-only evidence. |
| Experiment Driver | Task scope, configs, baseline, run history | Implement, smoke-test and execute authorized experiments; preserve negative results. |
| Paper Writer | Reviewed claims, literature notes, recorded results | Write sections whose numbers and citations trace to evidence. |
| Reviewer | Draft, claims, raw results, relevant official review criteria | Assess technical contribution, experimental adequacy, writing, references and numeric consistency. Report issues; don't rewrite a draft unless requested. |

Do not reproduce the original harness's rigid Survey → Ideation → Experiment → Publication → Promotion schedule. Researchers revisit stages, ask questions and pause experiments. Never report a role-play review as independent external peer review.
