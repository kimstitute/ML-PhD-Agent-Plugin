# Evidence-grounded writing

Adapted from Oh My Paper's Paper Writer role (MIT). Read the relevant reviewed claims, actual run results, literature notes and target draft. Keep the researcher's intended contribution and scope.

For numeric provenance, the project's imported backward-traceability reference may help; find it through `../research/references/private-sources.md`. Do not assume its LaTeX macros or fixed scripts exist in this project.

Map each empirical sentence to run IDs and metric locators, and each literature statement to a read source and section/page. Use proposed/partial claims only as clearly labeled hypotheses or limitations, never established findings. Do not fill missing numbers, citations or experiments with plausible values. DOI existence is not claim support.

For methods, distinguish implementation details from mathematical claims. For results, state evaluation conditions and uncertainty; mention meaningful negative findings. For related work, compare mechanisms and assumptions rather than keyword overlap. For rebuttals, map each reviewer concern to a response, evidence or explicitly pending experiment.

Write a separate draft artifact unless asked to edit the live manuscript. Check numeric consistency against the ledger, citation-key existence against the actual bibliography, and the target venue's current official rules when applicable. Preserve the user's requested language and style; don't rewrite unrelated sections.

Submit the draft through a task report and record remaining unsupported assertions in the handoff. Publication, uploads, collaborator messages and submission require separate user authorization.
